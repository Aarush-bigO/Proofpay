# Contributing to ProofPay

Thank you for your interest in contributing to **ProofPay**! We welcome contributions from developers, building code inspectors, and FinTech enthusiasts.

## Development Workflow

1. **Fork the Repository** and clone your fork locally:
   ```bash
   git clone https://github.com/Aarush-bigO/Proofpay.git
   cd Proofpay
   ```
2. **Install Dependencies**:
   ```bash
   npm install
   ```
3. **Create a Feature Branch**:
   ```bash
   git checkout -b feature/milestone-dispute-extension
   ```
4. **Run Verification Tests**:
   ```bash
   npm test
   npm run build
   ```
5. **Commit Conventions**:
   Follow [Conventional Commits](https://www.conventionalcommits.org/):
   * `feat: ...` for new functional capabilities
   * `fix: ...` for bug resolutions
   * `docs: ...` for documentation updates
   * `test: ...` for unit or integration tests

6. **Submit a Pull Request** against the `main` branch with a clear description of changes.
