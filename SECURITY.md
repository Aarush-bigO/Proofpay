# Security Policy

## Supported Versions

ProofPay prioritizes financial and data integrity. We actively provide security updates for the current release:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability or potential loophole in our **PayPal Orders v2 Escrow** state machine or multimodal verification verification contracts, please do **NOT** open a public issue.

Instead, please report it privately:
* **Lead Security Contact:** Aarush Bharti
* **Email:** [aarushbharti2005@gmail.com](mailto:aarushbharti2005@gmail.com)

Please provide:
1. Description of the vulnerability and attack vector.
2. Step-by-step reproduction instructions or proof-of-concept payload.
3. Potential impact on escrow holds or cryptographic certificates.

We commit to acknowledging your report within 24 hours and providing an initial mitigation timeline within 48 hours.
